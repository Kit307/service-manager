# Product

## Register
product

## Platform
web

React renders in a native macOS Tauri webview; this platform field describes the rendered interface, not distribution as a website.

## Users
Developers who want to open a code folder and manage its local services through a desktop interface and their AI coding clients.

## Product Purpose
Run, stop, restart, and inspect services without manual terminal management. Desktop controls, MCP, and a proxy script share one manager and the same logs.

## Positioning
One project workspace for the services a developer and their AI work on together.

## Brand Personality
Quiet, precise, practical. The user approved a Mac tool interface with most of the workspace allocated to logs.

## Anti-references
Decorative dashboards, large metric tiles, and terminal-only workflows. No invented service status or client connection claims.

## Design Principles
- A service's actual state drives the interface.
- Make the next lifecycle action visible.
- Keep logs readable without interrupting inspection.
- Show configuration and errors before executing commands.

## Accessibility & Inclusion
Keyboard-accessible controls, visible focus, text labels alongside status colors, readable contrast, and reduced-motion support are implementation requirements from the approved plan.
